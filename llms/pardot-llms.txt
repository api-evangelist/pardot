This file contains links to LLM-friendly markdown documentation pages.

## Overview

API reference and developer guide for Account Engagement (formerly Pardot), covering the Object API, Export API, and Import API across versions 3-5, used by developers to automate marketing workflows, manage prospects and campaigns, and integrate Account Engagement data with external systems.

## Account Engagement API

Enable marketers to create meaningful connections and generate more pipeline. Empower salespeople to close more deals.
